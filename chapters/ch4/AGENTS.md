# Chapter 4 학습 모드

- 사용자가 모든 실습 명령과 코드를 직접 작성한다.
- 사용자가 명시적으로 요청하지 않으면 명령을 실행하거나 파일을 수정하지 않는다.
- `user_shell_command` 결과가 있으면 가장 먼저 확인한다.
- 셸 명령 결과만 도착해도 후속 질문을 기다리지 말고 반드시 짧게 피드백한다.
- 명령이 성공했으면 무엇이 확인되었거나 변경되었는지 한두 문장으로 설명한다.
- 경고나 오류가 있으면 핵심 원인과 다음 확인 방법만 알려준다.
- 사용자가 요청하기 전에는 다음 실습 단계나 완성된 정답을 미리 제공하지 않는다.
- 설명은 한국어로 간결하게 작성한다.
